## 📌 About the Project

**Simon Says Game** is a fun and interactive memory game built using **HTML, CSS, and JavaScript**. Players must remember and repeat an increasingly long sequence of colored button flashes. Each correct round adds a new color to the sequence, making the game more challenging and testing the player's memory and concentration.

This project is designed to demonstrate core front-end development concepts such as DOM manipulation, event handling, random sequence generation, and game logic implementation.

---

## 🚀 Features

- 🎮 Interactive gameplay
- 🧠 Memory-based challenge
- 🎲 Random color sequence generation
- ✨ Button flash animations and effects
- 📈 Score and level progression
- 🔄 Restart game after game over
- 📱 Responsive and user-friendly interface
